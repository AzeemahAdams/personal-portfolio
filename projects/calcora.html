Overview

What is Calcora?

Calcora is a scientific calculator web app built entirely with vanilla HTML, CSS and JavaScript — no frameworks, no libraries. It handles everything from basic arithmetic to trigonometric functions, all wrapped in a carefully crafted dark UI with colour-coded buttons that make the experience intuitive at a glance.

The project was a deep dive into JavaScript logic, DOM manipulation, and clean UI design. The colour system — teal for trig, red for clear, orange for delete, purple for operators — creates a visual language users pick up instantly.

Try it Live

Scientific Functions

Full sin, cos and tan support with DEG / RAD mode switching.

Colour-coded UI

Teal, red, orange, purple and cyan keys — each colour has a purpose.

Keyboard Support

Type numbers and operators directly from your keyboard — no clicking needed.

Error Handling

Handles division by zero, invalid input, and edge cases gracefully.

Responsive Layout

Looks and works great on phones, tablets and desktops.

Zero Dependencies

Pure vanilla JS — fast load, no framework overhead, runs anywhere.
